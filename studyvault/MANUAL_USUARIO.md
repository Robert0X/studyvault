# StudyVault — Manual de usuario

Guía breve para usar cada parte del sistema.

## 1. Acceso
- Entra en **http://localhost/studyvault/**.
- **Iniciar sesión** con tu correo y contraseña, o **Registrarse** (pestaña en la misma pantalla).
- Cierra sesión desde el menú de usuario (arriba a la derecha).
- Botón 🌙 / ☀️ en la barra superior: cambia entre **modo claro y oscuro**.

## 2. Materias
- Menú **Materias** → "Nueva materia". Asigna nombre, descripción, ícono y color.
- Cada materia muestra su progreso. Botones para editar o eliminar (sin recargar).

## 3. Recursos
- Menú **Recursos** → "Nuevo recurso". Tipos: enlace, PDF/archivo, nota o video.
- Para PDF/imagen se sube el archivo (máx. 5 MB).
- Busca y filtra en tiempo real por materia, tipo o estado.
- Cambia el estado (Pendiente / En progreso / Completado) desde la misma tabla.

## 4. Unidades (progreso de un "libro grande")
- En un recurso, botón **Unidades** (icono de lista).
- Agrega capítulos uno a uno o **genera N de golpe** ("Capítulo 1..N").
- Marca cada unidad como completada → el recurso muestra el **% real**.

## 5. Flashcards (memorización)
- Menú **Flashcards** → "Nueva tarjeta" (anverso, reverso, ejemplo, nivel CEFR).
- También puedes **guardar palabras desde el diccionario** (barra lateral).
- **Estudiar**: la app te muestra solo las tarjetas que toca repasar hoy (SM-2).
  - Modos: **Clásico**, **Cloze** (rellena el hueco) y **Producción** (escribe la palabra).
  - Califica: Otra vez / Difícil / Bien / Fácil (o teclas 1–4; Espacio voltea).
- "**Por nivel**": estudia solo un nivel (A1–C2). "**Exportar**": descarga CSV para Anki.

## 6. Diccionario de inglés (barra lateral)
- Escribe una palabra y pulsa buscar.
- Verás: significado, pronunciación (🔊), **se usa con** (colocaciones) y **ejemplos** reales.
- "Guardar como tarjeta" crea una flashcard con esa información.

## 7. Programación Competitiva
- Menú **Competitiva**. Escribe tu **handle de Codeforces** y "Guardar".
- "**Sincronizar**": importa tu rating y los problemas que has resuelto.
- "Sincronizar catálogo" habilita **sugerencias** de problemas a tu nivel (+100/+300).
- Marca un problema resuelto con 🔄 para **programarlo a repaso** (SM-2) → pestaña "Repasar".
- "Plantillas": guarda tus snippets de código (DSU, etc.) y cópialos con un clic.
- Verás también los **próximos concursos**.

## 8. Metas
- Menú **Metas** → "Nueva meta" (ej. "Inglés B2 para diciembre", con fecha objetivo).
- Entra a la meta y **agrega recursos con un peso** (cuánto aporta cada uno).
- La meta muestra el **% ponderado** y si vas **En camino / Atrasado** según la fecha.

## 9. Temporizador
- Menú **Temporizador**. Pomodoro 25/5: "Iniciar".
- Al completar un bloque, registra automáticamente el tiempo.
- Puedes elegir qué recurso estudias y registrar minutos manualmente.
- Verás minutos de hoy/semana, **racha** y un **heatmap** de constancia.

## 10. Reporte semanal
- Desde el Dashboard → "Reporte semanal": tiempo vs semana previa, tarjetas repasadas,
  problemas resueltos, racha y estado de tus metas.
